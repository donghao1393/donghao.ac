## 做了什么

一个基于 R Shiny 构建的 NLP 预测模型交互式 Demo。用自然语言输入文本，模型给出实时预测结果——不用写代码，不用配环境，打开浏览器就能试。

## 技术栈

R · Shiny · NLP · Machine Learning · shinyapps.io

## 为什么做这个

这是数据科学能力的直接展示——从数据清洗、特征工程、模型训练到交互式部署的完整链路。也是我硕士期间探索 LLM + 传统 NLP 混合方案的一个实验产物。
